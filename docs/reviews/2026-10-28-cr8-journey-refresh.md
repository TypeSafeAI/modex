# CR-8 integrated activity and instructions journey

The integrated journey now reaches R1 → R2 activity → R3 review instructions → R4 split view through real Electron and the production read service with a synthetic `gh`. The previous journey explicitly deferred R2/R3 even after their producer implementations landed. This change extends the existing test; it does not change product behavior or enable Code Review in built apps.

## Verified scope

Twelve synthetic timeline comments make the overview scrollable. An explicit empty deployment response allows the production service to distinguish complete activity from missing metadata. The journey scrolls the last comment into view, verifies that the overview moved while the inbox did not, opens instructions, verifies initial textbox focus and the version-zero local scope, captures the open popover, then presses Escape and checks returned focus and preserved overview scroll. Existing navigation, split-pane geometry, minimum-window, read-only endpoint, provider-start and unchanged-checkout assertions remain. The only extra allowed read is the exact synthetic repository/head deployment-list request. No provider inference or actual GitHub mutation occurs.

This covers the R2/R3 fixture interaction gap in #327. It does not establish original-reference fidelity, human VoiceOver acceptance, authenticated reads, live native-provider execution or disposable-target writes. The R4 portion still covers the existing split host and geometry, not a new populated-diff journey. Producer tests retain their separate detailed coverage, and the broader CR-8 acceptance matrix remains incomplete.
