request generation checks remain separate from display text and Jev's digest.

The remaining reproducible defect was a question draft disappearing when its thread view
unmounted. Choices and text now live in a window-owned cache scoped by thread and request ID.
Closing a request clears its draft even while another thread is selected; removing or retiring
its thread clears that thread's cache. Secrets remain in memory and never enter composer
recovery, storage, events, telemetry or exports. Closing the window intentionally discards them.
