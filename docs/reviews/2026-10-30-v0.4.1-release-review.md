# v0.4.1 release review

Desktop v0.4.1 is a patch release. It fixes the three observations from the CF-7 close-out's live
runs (#280):

- a turn's files list no longer looks complete when a shell command may have changed files no CLI
  named;
- a thread named after its opening message is cut at a word break with "…", not mid-word.

Val asked on 2026-10-30 for the CF-7 work to land and the next patch release to ship. The iPhone
Companion stays at 0.4.0 (9); nothing in this release changes it.

This preparation starts from protected `main` at `9f85d61` (#455), which includes #450 as
`108b814`. It changes only the desktop version and the release records. The tag source is this
PR's squash merge on protected `main`.

## Candidate behavior and compatibility

- **Updates.** v0.4.0 reaches v0.4.1 through the background update: a check downloads and verifies
  it without a click, and it installs on **Restart to update** or the next time Modex quits. v0.2.0
  and older still need one **Download update** click. Windows and Linux still install by hand.
  [Download and restart](../update-recovery.md#download-and-restart).
- **Files touched.** A finished turn that ran a command which may have written files, and is
  neither a check nor known to be read-only, now shows that command under the files list. The label
  reads "N, maybe more", or "not listed" when no file was named. A turn that only reads, or only
  edits through patch tools, looks as before.
  [Context map](../task-context.md#context-map).
- **Saved notes.** Notes and task records saved by v0.4.0 reopen unchanged, without the command
  list. Nothing is backfilled or inferred. A new save of the same turn writes the list.
- **Thread titles.** Only new threads change. An existing thread keeps its title, and a Retry of a
  first turn that carries the old 60-character cut is still renamed once the turn completes.
- **Not changed.** The release workflow, signing scripts, release verifier, native updater verifier
  and desktop build hooks are unchanged from v0.4.0, so no rc rehearsal is needed.
