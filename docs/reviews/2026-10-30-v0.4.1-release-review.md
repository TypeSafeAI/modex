## Candidate behavior and compatibility

- **Updates.** v0.4.0 reaches v0.4.1 through the background update: a check downloads and verifies it without a click, and it installs on **Restart to update** or the next time Modex quits. v0.2.0 and older still need one **Download update** click. Windows and Linux still install by hand. [Download and restart](../update-recovery.md#download-and-restart).
- **Files touched.** A finished turn that ran a command which may have written files, and is neither a check nor known to be read-only, now shows that command under the files list. The label reads "N, maybe more", or "not listed" when no file was named. A turn that only reads, or only edits through patch tools, looks as before. [Context map](../task-context.md#context-map).
- **Saved notes.** Notes and task records saved by v0.4.0 reopen unchanged, without the command list. Nothing is backfilled or inferred. A new save of the same turn writes the list.
- **Thread titles.** Only new threads change. An existing thread keeps its title, and a Retry of a first turn that carries the old 60-character cut is still renamed once the turn completes.
- **Signed rehearsal.** `v0.4.1-rc.1` runs the existing protected Release workflow on the combined validation source to investigate packaged acceptance with a consistent Developer ID signature. Its draft must never be published.
