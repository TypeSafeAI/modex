# Desktop v0.0.6 release review

The release candidate is `main` at `fc8c699` plus release PR #97. The previous
release is v0.0.5 (`e2c2fbc`). The planned distribution is macOS Apple Silicon, Developer ID
signed for Soul Protocol LLC (`9LR8Z8UQ9X`), notarized and stapled. The monorepo and core package
keep their existing versions.

## Scope

| Area | Change |
| --- | --- |
| Graphite UI and privacy | #80 centers content after hiding the sidebar. #89 refines the dark surfaces, cool accents, type hierarchy and composer; fixes the follow-up placeholder overlap and makes offline screenshot capture deterministic. #100 adds Streamer Mode to redact sensitive transcript content. |
| Input and project safety | #93 restores an unsent message after a failed send or thread creation without overwriting newer typing. #94 clears drafts and thread view state when a project is removed, leaving files on disk. |
| Changes and test reliability | #82 handles discard in an unborn repository. #85 surfaces Git diff failures and handles rename destinations beginning with `-`. #102 scopes Changes status, diff, and revert to the selected project when it is a subdirectory of a repository. #84 drains the EPIPE test fixture before blocking the event loop; #98 waits for the terminal supervisor to stop before testing close. |
| Account readiness | #96 separates CLI installation/version, structured sign-in status and unverified model access. Status checks run no coding turn; missing, older and failed CLI checks do not claim readiness. |
| Provider research | #95 records conditional Gemini and Grok CLI/ACP feasibility decisions. Neither backend is enabled. |

Approval rules remain off. The auth, approval, and browser-review branches are in flight and
have their own acceptance gates. This release contains the reviewed changes above.

## Verification

- On the rebased release branch, `npm run build && npm test && npm run typecheck` passed:
  15 core and 192 desktop unit tests. `npm run test:e2e` passed all 85 Electron tests,
  including Streamer Mode, scoped Changes, composer recovery, account status, project
  removal and PTY lifecycle.
- An ad-hoc `npm run dist -w @modex/desktop` produced a 0.0.6 arm64 bundle, DMG and ZIP
  from the rebased branch. The bundle icon matches `build/icon.icns`; `hdiutil verify` and
  `unzip -tq` passed. All 85 Electron tests passed with `MODEX_PACKAGED_APP` pointed at
  the 0.0.6 bundle. The ad-hoc artifact is not for publication.
- The local release script built and notarized the 0.0.6 app and DMG with Soul Protocol LLC's
  Developer ID identity. Its independent `--verify` pass confirmed strict nested signatures,
  hardened runtime with library validation, Gatekeeper acceptance for app and DMG, stapled
  tickets on both and on the app inside the ZIP, container integrity, arm64 version, and icon.
  The signed packaged app passed all 85 Electron e2e tests. The e2e launch helper now polls
  native window visibility: repeated signed launches exposed a missed one-time `show` event
  after DOMContentLoaded, which had stalled the initial packaged run.
- Release PR exact-head macOS CI: pending after the signed rehearsal record is committed.
- Signed tag, protected `Release` workflow, downloaded-asset verification and publication:
  pending.

## Proof limits

Offline fixtures do not prove live Claude or Codex model access, subscription eligibility,
or the conditional Gemini/Grok backend contracts. Human VoiceOver acceptance and installation
on a fresh Mac remain untested. Windows and Linux installers and auto-update are not in this
release.
