## Candidate behavior and compatibility

- **Updates.** v0.4.0 is the first release that v0.3.0's background update reaches. A v0.3.0
  check downloads and verifies v0.4.0 without a click, and it installs on **Restart to update** or
  the next time Modex quits. v0.2.0 and older still need one **Download update** click. Windows and
  Linux still install by hand. [Download and restart](../update-recovery.md#download-and-restart).
- **Transcripts and notes.** Old transcripts and notes read unchanged. Notes saved before CF-7's
  task view have no task view, and earlier turns have no files-touched or verification line. Nothing
  is backfilled or inferred.
- **The event journal stays opt-in** (`MODEX_EVENT_JOURNAL=1`). Questions and a plan saved by v0.3.0
  load closed and readable on every client (`conversation-migration.test.ts`).
- **iPhone.**
  - Companion 0.4.0 (9) answers an agent's question card through the Mac's broker. A secret goes in a
    secure field that is held only in memory.
  - It closes cards that were answered, withdrawn or stopped while it was away.
  - Older Companion builds keep receiving a question as text to answer on the Mac.
  - Build 9 supersedes 0.3.0 (8), which was never uploaded.
- **Codex Plan mode** uses Codex's plan collaboration mode with the picked model and effort, and stays
  read-only. A Codex that refuses the mode falls back to the old prompt, with a notice.
- **Code Review is hidden.** Built apps show the destination only when the local switch
  `modex.codeReview` is `on`; development builds show it. Gate A (#319) is not accepted, so this
  release does not offer Code Review.
- **Local models.** Main keeps loopback-only connection profiles and reads bounded model metadata
  through a local-only IPC channel, under the metadata exception that AGENTS.md records as Val's
  approval. There is no UI, no execution and no inference, so nothing in the app reaches it yet.
- **Platforms.** macOS arm64 is Developer ID signed (Soul Protocol LLC) and notarized by the Release
  workflow. Windows and Linux candidates are built and checked as for v0.3.0. Whether they are
  published is decided at publication.
