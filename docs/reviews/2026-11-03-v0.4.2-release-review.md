## Behaviour and compatibility

- **Updates.** v0.4.1 reaches v0.4.2 through the background update, as v0.4.1 did from v0.4.0. No release workflow, signing script or updater file changed since v0.4.1, so no rc rehearsal is required by [the release procedure](../release-signing.md#rehearsing-with-an-rc-tag).
- **Code Review stays hidden.** A fresh built app doesn't show it, and makes no Code Review read. Settings → General → "Show Code Review in the rail" is new and visible to everyone, so people can now find and turn on a workspace whose gates are still open. Someone who set the old `modex.codeReview` switch to `on` keeps it. Any other value keeps it hidden.
- **Account pool.** New in Settings → Coding CLIs → Claude Code and opt-in. Unit and E2E coverage use a synthetic `claude`. No live OrcaRouter turn, second subscription or real limit message has run ([limits](../claude-accounts.md)).
- **A feature in a patch.** The account pool and the new setting are additions, not fixes. Val chose the patch number knowing the setting; v0.4.2 is also the first release to carry the pool.
