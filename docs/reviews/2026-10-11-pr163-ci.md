## Streamer assertion follow-up

The [desktop job on `9c502b0`](https://github.com/TypeSafeAI/modex/actions/runs/38160103520/job/114531026537)
passed the attachment tests, then failed `Space comment quotes mask selected
fragments while keeping original text`. After posting a comment, its masking
assertion called `Range.comparePoint` with a quote text node from a different tree,
raising `WrongDocumentError` instead of allowing the polling assertion to retry.
Highlight ranges can briefly refer to the previous quote before the observer refresh.

The assertion now first checks `Range.intersectsNode`, which rejects unrelated
roots without throwing. It still compares both endpoints of the current quote:
stale ranges alone cannot satisfy the assertion. A deterministic regression prepends
a detached range ahead of the real highlight. That reproduced the exact CI exception
before the guard and passes afterward. No production redaction or stored values change.

Verification: all seven Streamer Mode e2e tests passed (16.9 seconds), including

assertions. The build and full unit rerun passed: 621 passed, one skipped. At that
