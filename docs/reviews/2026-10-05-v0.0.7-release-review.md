# v0.0.7 patch release

## Scope

- Ship the release notification banner, OpenCoven theme, and automatic CLI discovery with
  verified overrides already merged after v0.0.6.
- Polish the banner's hierarchy, download affordance, action/focus states and minimum-window
  layout in both themes. Check for a rollout when the user returns to the app, using the
  existing main-process cache and request coalescing.
- Include the merged approval-rules editor with its production gate still off.
- Expand Play walkthrough on the landing page into a full-width presentation with
  pause/resume, replay, native dialog keyboard containment, Escape and focus restoration.
- Adopt Val's official logo across macOS app/DMG icons, desktop branding, companion
  App Store icon and UI, website navigation/favicon/social preview and README artwork.
  Preserve the original transparent PNG byte-for-byte and generate platform assets reproducibly.
- Ship the official identity in Companion build 3, then prepare build 4 with persistent
  reconnection, local discovery, explicit Mac revocation handling and a copyable pairing link.
- Update the site's Mac download only after the signed release is public. iPhone stays
  **Coming soon** on the public website.

The banner first ships in v0.0.7. Users of v0.0.6 or earlier must install this patch manually;
those binaries cannot display a feature added after they were built. After installing
v0.0.7, a newer published stable release with a matching Mac installer produces the banner.
Updates open the release page; installing remains a deliberate user action.
