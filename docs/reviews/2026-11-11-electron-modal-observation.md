## Bounded diagnostic candidate

Only the synthetic Code Review test harness changes. Immediately after a successful Electron launch it retains that owned child's stderr in an exclusive mode0600 artifact, capped at 256 KiB. Listener and descriptor cleanup occurs at capacity, child close, explicit stop or write failure; diagnostic failures preserve the original child outcome. Output is written as it arrives, so a worker teardown timeout need not finish before evidence exists. The artifact is a bounded prefix and may omit later errors after capacity.

The harness also installs a self-contained `uncaughtExceptionMonitor` observer in the owned Electron main process. It writes at most eight records, each with at most 4,096 stack characters, through a synchronous stderr write whose failures are caught. It never handles the exception, replaces Electron's existing handlers or changes exit status. Capturing stderr may alter scheduling and the observer starts only after launch; failures before installation, native dialogs unrelated to uncaught JavaScript exceptions and exact timing remain outside its coverage. It does not dismiss dialogs, change production code, weaken assertions, extend deadlines or establish the cause of the historical stall.
