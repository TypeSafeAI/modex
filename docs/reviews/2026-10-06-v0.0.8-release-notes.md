# Modex v0.0.8

- See each thread's provider, model, current branch and GitHub PR state in the left sidebar.
  Open a PR directly from its draft, open, merged or closed label. Install and sign in to
  the GitHub CLI (`gh auth login`) to read PR metadata; unavailable access is shown explicitly.
- Review numbered diffs beside a filterable file tree in the new tabbed workspace. Keep
  file previews, terminal sessions and isolated browser tabs together, or expand to full view.
- Start a new project or chat from the polished empty workspace screen.
- Recover from coding CLI failures with clearer Retry and connection controls.

The website now refreshes release downloads and GitHub counts automatically and links to
the Companion TestFlight invitation. Enrollment depends on Apple's current availability.

This release targets macOS on Apple Silicon. Mac App Store submission and iPhone delivery
remain separate tracks. Approval-rule automation remains gated off in production.

The macOS app and installer are Developer ID signed, notarized, and stapled. Download the Apple Silicon DMG below, or use the ZIP. SHA256SUMS.txt and verification-v0.0.8.txt document the verified CI artifacts.
