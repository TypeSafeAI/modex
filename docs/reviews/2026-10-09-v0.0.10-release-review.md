Claude and Codex receive scoped MCP tools for project-enabled knowledge and notes.
Chat and plan turns stay read-only. Revision checks, attributed history, recoverable
trash and draft copies preserve concurrent edits. Space storage upgrades to version 2
on mutation; older builds reject that format. Export notes as Markdown before downgrading.

Mac App Store and iPhone distribution remain separate tracks. Physical iPhone and
human VoiceOver acceptance were not performed for this release.

## Shutdown race found during release validation

The first release PR macOS run (`37970304941`, job `113954926581`) passed 160
of 161 desktop tests but timed out on an immediate `app.close()`. A local signed
repetition reproduced it on attempt 8 of 8. A separate uninstrumented probe reproduced
it on attempt 25, and a native process sample plus the error dialog identified
`BrowserWindow.visibilityChanged`: Electron 44.4.5 retained listeners that call native
window methods after destruction. Its uncaught-exception dialog blocked quitting.

The fix removes only `show`, `hide`, `minimize`, `maximize`, and `restore` listeners
on `closed`, before other window cleanup. Live visibility events and a vetoed close
remain intact. A deterministic Electron regression emits those notifications after
closing a real window: five `Object has been destroyed` errors before the patch,
none after. Independent lifecycle review confirmed the ownership boundary.
The initial rehearsal hashes above are superseded; replacement artifact validation
is recorded below. Failed trace and local sample remain in `/tmp/modex-pr151-e2e/` and
`/tmp/modex-quit-live.sample`.
